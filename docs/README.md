# Project documentation

The repository root contains only the project README and runtime configuration. Supporting documentation is grouped here by purpose.

## Current references

- `product/product-design-prd.md` - product and design requirements
- `assets/asset-inventory.md` - deployed model inventory and provenance
- `assets/anatomy-improvement-plan.md` - anatomy asset and interaction roadmap
- `assets/heart-source-evaluation.md` - heart source evaluation
- `design/handoffs/stranerd-design-system.dc.html` - archived design-system handoff

## Supporting material

- `business/` - pitch and business material
- `design/archive/` - superseded demo specifications
- `design/references/` - visual references and benchmarks
- `product/archive/` - historical implementation plans
- `research/` - exploratory product research

Files under `private/` are local-only and ignored by Git because they may contain credentials. Generated learner notes remain under `Materials/output/` because the importer depends on that path.
